## Sign-Off

Every commit must carry a `Signed-off-by` line, which certifies the terms of the [Developer Certificate of Origin](https://developercertificate.org/) and this document. Add it with:

```sh
git commit -s
```

Pull requests with unsigned commits cannot be merged.


## Pull Requests

- Keep changes focused and small.
- Describe what changes and why.
- Follow the existing code style.
- Add or update tests where it makes sense.
